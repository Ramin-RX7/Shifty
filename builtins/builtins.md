# Built-ins

This section of the docs covers the built-ins in the language.

As there are several types of language-specific parts in this section, they are all separated into their own doc.

1. [[primitive_types|Primitive Types]]:  Simple data types that most of other types are built upon these.
2. [[composite_types|Composite Types]]:  Other data types that are a bit more complex than primitive types.
3. [[builtins/functions|Functions]]: functions that are predefined by the language
4. [[builtins/factories|Factories]]: different features of language that let users make their own data types.
5. [[builtins/errors|Errors]]: list of errors implemented and used by the language

Built-ins may have more control over the objects and can have their own structure of `objects mapping`.
